# toolbench docs

| File | What it is |
|---|---|
| `taxonomy.md` | The package map: every approved package, its SHORT, layer and patterns |
| `DECISIONS.md` | D-ids, each with the alternative that lost |
| `ASSUMPTIONS.md` | Anything built without a decision |
| `CHANGELOG.md` | What shipped, with IDs |
| `TODO.md` | Open items |
| `sources/` | One file per outside source: what it was used for, which IDs use it |
| `requests/` | Saved request prompts |
| `specs/` | One page per package, written before its code (`TEMPLATE.md`) |
| `standards/` | Project-wide coding standards every consumer follows (`logging.md`: the house logging format) |
| `<topic>_<YYYY-MM-DD>/` | One folder per piece of work, each with a README |
