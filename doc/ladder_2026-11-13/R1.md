## Notes
- Repos read: 23 (the task list names 23 including go_23; BRIEF.md says 22). go_16 and go_22 do not exist in my range.
- Standard patterns missing from code-heim in this range: or-done, tee, bridge, semaphore, errgroup, singleflight, sync.Pool, generator as its own lesson, panic-to-error (every repo here panics or swallows panics).
- Outdated idioms: `go func(job Job){}(job)` loop-var copy (go1.22 removes the need); `for i := 0; i < n; i++` → range-over-int; `map[string]interface{}` → `any`; go-redis v8/v9 under github.com/go-redis → github.com/redis/go-redis/v9; `log.Logger` per level + `init` → `log/slog`; `time.Sleep` goroutine per cache entry → one timer/heap; `context.Background()` inside library funcs.
- Defects worth remembering as test cases: go_11 cache hit falls through and writes twice; go_8 unlock deletes another holder's lock; go_14 builder reuse leaks state; go_20 confinement owner goroutine never exits; go_21 stages leak when the consumer stops early; backendAdvo metabolic_reports.go:575 `defer func(){ recover() }()` swallows panics silently.
- go_23 `before/app_config` reads YAML into a global: a file source for `config.Layered` would need a YAML dependency (decision for Devin; JSON via stdlib is the dependency-free alternative).
- calcbench gaps: MISSING integer ceiling division (CeilDiv int64) for page counts. calcbench ALG-LIST-015 LRUCache and ALG-QUEUE-002 CircularBuffer are not safe for concurrent use; toolbench wraps them with a mutex rather than rewriting.
