## Notes
- BRIEF says 14 columns but names 13; this table uses the 13 named columns, in that order.
- Rows per tier: T0 2 · T2 5 · T4 3 · T5 5 · T6 6 · SKIP 6.
- Missing from code-heim in this range (standard patterns to add from authority): singleflight, retry/backoff
  (only implied by MaxFails/Retry.Max), dead-letter channel, outbox (go_44 publishes without a transaction: dual
  write), idempotency key, rate limit middleware, request timeout/deadline middleware, CSRF (now stdlib 1.25).
- Outdated idioms seen: `r.Method != POST` checks (go1.22 routing); context-less `DB.Begin` (go1.8 BeginTx);
  `...interface{}` job args (generics); reflect.Call in cache helper (generics); `for {}` to block main (use
  `<-ctx.Done()`); signal channel + goroutine `os.Exit` (signal.NotifyContext); math.Ceil on float for page
  count; `io.MultiWriter` fan-out of logs (slog.NewMultiHandler, go1.26); custom "ttl" JWT claim (RFC 7519 "exp").
- Defects worth knowing (not to copy): gin c.Abort()/AbortWithStatus without return (go_30 middlewares/auth.go:16,
  go_36 middlewares/auth.go:16-50); secrets committed (go_31 config.yml:4-5, go_36 hard-coded HMAC key);
  go_26 write_to_file.go references undefined `multiWriter`; go_47 header injection and template path traversal.
- backendAdvo swallows panics silently: knowledgebase/pending/analytics/metabolic_reports.go:577,584
  (`defer func() { recover() }()`), strong case for `panics.Try`.
- calcbench gaps: MISSING CeilDiv (overflow-safe integer ceiling division). Backoff with jitter not in calcbench
  either (expected from the retry rows of other readers). LRUCache/LFUCache are single-goroutine: a concurrent
  cache wraps them with a mutex.
- red_lite_cache's logger comments cite code-heim go_26_slog (internal/logger/logger.go:28); per sources.md the
  citation should move to the slog docs.
