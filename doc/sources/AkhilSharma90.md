# AkhilSharma90 (github.com/AkhilSharma90)

**What it is**: the personal GitHub account of a YouTube and course author: 192 repositories on 2026-11-13, of
which 98 are Go (79 by GitHub language detection plus 19 whose name says Go) and 92 hold Go code; the rest are
Rust, JavaScript/TypeScript, Python, Solidity and Hugo sites. Unlike code-heim (one technique per repo) most are
whole small applications (CRUD APIs over several frameworks, blockchains, scrapers, bots, LLM clients, a CQRS
microservice set, a monolith-to-microservice series, a 600-file Go bootcamp). Last pushed 2017-03 to 2026-05.

**What it is used for**: a READING LIST ONLY, the second after code-heim (decision D-004 applies): which
patterns matter to a working Go service, seen through applications rather than lessons. It is never copied and
never cited. Every pattern it shows is re-researched against today's Go (go1.27) and cited to its authority
(`.claude/rules/sources.md`). No toolbench file adapts AkhilSharma90 code, so no file carries an attribution
notice; if one ever does, its header carries the notice of that repository's licence.
