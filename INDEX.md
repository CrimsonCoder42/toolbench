One row per exported function, method, type, constant or variable that carries an ID, sorted by ID. Find by tag
or words; find the code with `grep -rn "ID:          <the id>"`. Does is the package doc.go line; Pattern,
Goroutines, Authority and Tags match the doc comment word for word, several `Authority:` lines joined by "; " in
the order of the comment, "-" where a label does not apply. A "|" inside a cell is written "\|". REMOVED rows stay
forever. The rows are GENERATED from the code (`go run doc/foundation_2026-11-13/gen_index.go <out>`, the
mechanism of calcbench D-070), never typed by hand, and `testing/index_test.go` fails when the code, the package
doc.go lists, this file and doc/taxonomy.md disagree.
